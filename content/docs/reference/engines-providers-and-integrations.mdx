If you want the mechanics behind any of this, the deeper explanation lives in `Engines and runtime` and `Configuration`. This page is just the compact reference view.

## Engines

Sentinel supports ten chat engines. Every engine except `sentinel` is a local coding agent, and each can have several [instances](/docs/engines-and-runtime/engines-overview#instances).

| Engine        | Meaning                                                              | Stability    |
| ------------- | -------------------------------------------------------------------- | ------------ |
| `sentinel`    | Built-in harness and built-in engine path                            | Stable       |
| `codex`       | Codex CLI, through the Codex app-server                              | Stable       |
| `claude`      | Claude Code, through the Claude Agent SDK                            | Stable       |
| `copilot`     | GitHub Copilot, through the Copilot SDK and its bundled runtime      | Stable       |
| `cursor`      | Cursor Agent, over ACP                                               | Stable       |
| `opencode`    | OpenCode 1.x or 2.x, through a local OpenCode server                 | Stable       |
| `grok`        | xAI Grok Build, over ACP                                             | Experimental |
| `antigravity` | Google Antigravity's ACP server, installed by Sentinel               | Experimental |
| `pi`          | The Pi coding agent, over JSONL RPC                                  | Experimental |
| `acp`         | ACP Registry agents (Gemini CLI, Devin, Mistral Vibe, and others) or any ACP command | Experimental |

## Engine settings

| Setting                     | Where                                   | Default |
| --------------------------- | --------------------------------------- | ------- |
| Model and version updates   | Settings → Engines, or `SENTINEL_DISABLE_REMOTE_MANIFEST` | On      |
| Check for CLI updates       | Settings → Engines, or `SENTINEL_DISABLE_ENGINE_UPDATE_CHECKS` | On      |

## Model providers

Current AI provider support includes OpenAI, Anthropic, Google AI Studio, Google Vertex AI, xAI, Azure OpenAI, Amazon Bedrock, Groq, Cohere, Moonshot AI, Mistral, DeepSeek, Ollama, OpenRouter, and Vercel AI Gateway.

## Search providers

Search provider support includes Exa and SearXNG.

## Voice transcription providers

Voice transcription provider support includes OpenAI, Groq, and Azure.

## Integration providers

Integration support currently covers Gmail, Google Calendar, Google Drive, Airtable, Slack, Notion, GitHub, Linear, PostgreSQL, MySQL, MongoDB, Yahoo Finance, arXiv, and PubMed.

## MCP transports

Sentinel supports `stdio` and `http` MCP transports.
